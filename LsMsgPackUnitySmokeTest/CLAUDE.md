# Unity smoke test (LsMsgPackUnitySmokeTest)

LsMsgPack in Unity itself (docs/Unity.md): the data of LsMsgPackAotSmokeTest's model, minus what .NET Standard 2.1 lacks (DateOnly, Half, Int128, immutable collections, System.Text.Json's attributes; record structs: Unity compiles C# 9), checked in the editor (Mono JIT), a Mono player and IL2CPP players. Not in the solution or CI: it needs Unity (~/Unity/Hub/Editor/<version>/Editor/Unity, `UNITY=` overrides; written against 6000.6.10f1 with the Linux Build Support (IL2CPP) module and an activated license).

- `run.sh [editor|mono|il2cpp-<level>[+keep]...]` (default: editor mono il2cpp-Minimal il2cpp-High il2cpp-High+keep; `+keep` writes a link.xml keeping the model, Unity's way to keep members from its stripper): builds `Libs/` (the netstandard2.1 DLLs of LsMsgPack, LsMsgPack.Core and LsMsgPackDebug, copied into `Project/Assets/Plugins/LsMsgPack`) and the generator (`Analyzers/`, its committed .meta carries the label `RoslynAnalyzer`, no platform), runs `Golden/` (.NET 10, the same model and checks: writes `golden.txt`, name|hex|values per option set), then Unity headless (`-batchmode -nographics -executeMethod LsMsgPackUnitySmoke.Editor.SmokeBuild.Build|RunInEditor`) and each player. Results in `out/<step>.txt` (the logs next to them), `diffhex.py out/<step>.txt` finds the first differing bytes. An IL2CPP build takes 1.5-2 minutes, the whole run ~7.
- Each player checks every option set with the runtime plans and with `SmokeContext` (the generator's context), and Unity's own types (`GameState`: Vector3, Quaternion, Color, Vector2Int; `PlayerData`: a `[SerializeField]` field). Timings per invoice are printed for comparing the backends.
- Not System.Runtime.CompilerServices.Unsafe: Unity has its own (10.0), the NuGet copy (6.0) is not needed.
- `repro.sh` + `Repro/`: IL2CPP's internal error on `Unsafe.Unbox<T>` in a generic class, without LsMsgPack (variants `UNBOX`, `STRONGBOX`, `CAST`, combined with `ONLY_PLAIN`/`ONLY_VECTOR3`), for a report to Unity; LsMsgPack works around it (`LsMsgPackCore/Meta/BoxedValue.cs`).
- IL2CPP's `float.NaN`/`double.NaN` are positive NaNs (CoreCLR's negative): the sample builds its NaNs from their bits.
- `.gitignore`: Unity's Library/Logs/UserSettings, Builds, out, the copied DLLs and the scenes and link.xml the build script writes; `.meta` files are re-included (the root ignores them).

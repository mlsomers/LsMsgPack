# Unity smoke test (LsMsgPackUnitySmokeTest)

LsMsgPack in Unity itself (docs/Unity.md): the data of LsMsgPackAotSmokeTest's model, minus what .NET Standard 2.1 lacks (DateOnly, Half, Int128, immutable collections, System.Text.Json's attributes; record structs: Unity compiles C# 9), checked in the editor (Mono JIT), a Mono player, IL2CPP players, WebGL players (headless Firefox) and Android players (a phone on adb). Not in the solution or CI: it needs Unity (~/Unity/Hub/Editor/<version>/Editor/Unity, `UNITY=` overrides; written against 6000.6.10f1 with the Linux Build Support (IL2CPP), WebGL Build Support and Android Build Support (with its OpenJDK, SDK and NDK) modules and an activated license; WebGL also needs `firefox` and `python3`, Android a device on adb (`ADB=` overrides ~/Android/Sdk's, else Unity's own)).

- `run.sh [editor|mono|il2cpp-<level>[+keep]|webgl-<level>[+keep]|android-<level>[+keep]...]` (default: editor mono il2cpp-Minimal il2cpp-High il2cpp-High+keep webgl-Minimal, plus android-Minimal when adb has a device; `+keep` writes a link.xml keeping the model, Unity's way to keep members from its stripper): builds `Libs/` (the netstandard2.1 DLLs of LsMsgPack, LsMsgPack.Core and LsMsgPackDebug, copied into `Project/Assets/Plugins/LsMsgPack`) and the generator and the analyzers (`Analyzers/`, their committed .meta files carry the label `RoslynAnalyzer`, no platform), runs `Golden/` (.NET 10, the same model and checks: writes `golden.txt`, name|hex|values per option set), then Unity headless (`-batchmode -nographics -executeMethod LsMsgPackUnitySmoke.Editor.SmokeBuild.Build|RunInEditor`) and each player. Results in `out/<step>.txt` (the logs next to them), `diffhex.py out/<step>.txt` finds the first differing bytes. An IL2CPP build takes 1.5-2 minutes, the whole run ~7.
- The analyzers: `Assets/AnalyzerSamples/` (an editor-only assembly definition) has deliberate warnings (LSMP001, LSMP004, LSMP010); the editor step looks for them in `out/editor.log`, and fails on any LSMP008 (Unity's engine structs are not another project's classes). Unity logs warnings only when it compiles, so run.sh writes a new `Stamp.cs` there each run (ignored by git).
- WebGL and Android (`WebRunner.cs`): no command line or files in a browser or on a phone, so `serve.py` serves the build (WebGL), `GET /golden.txt` and `POST /result` (the report, then it stops; exit code 3 when none came in 10 minutes). Firefox runs headless with a profile under `out/` (snap's Firefox has its own /tmp) that writes the page's console to `out/webgl-<level>.log`. The build is uncompressed (the server sets no Content-Encoding); exceptions stay Unity's default (explicitly thrown ones only), as a game ships.
- Android: an IL2CPP ARM64 APK (`com.lsmsgpack.smoke`, debug-signed, HTTP allowed), `adb install -r`, started with `monkey`; the app talks to 127.0.0.1:8765 on the phone (`WebRunner.AndroidPort`), which `adb reverse` forwards to serve.py. Unity's log: `adb logcat` into `out/android-<level>.log`. run.sh wakes the screen and waits up to 2 minutes while the lock screen shows (behind it Android pauses the app at once).
- Each player checks every option set with the runtime plans and with `SmokeContext` (the generator's context), and Unity's own types (`GameState`: Vector3, Quaternion, Color, Vector2Int, Rect and Bounds by their properties, and with a surrogate converter (`RectConverter`, the one in docs/Unity.md) and `BlitConverter<Bounds>`; differences of stripped types would be reported, not counted, for the runtime plans without a link.xml, but `SmokeContext` lists `GameState`: its generated code calls every accessor of those structs, which keeps them for the whole build; `PlayerData`: a `[SerializeField]` field). Timings per invoice are printed for comparing the backends.
- Not System.Runtime.CompilerServices.Unsafe: Unity has its own (10.0), the NuGet copy (6.0) is not needed.
- `repro.sh` + `Repro/`: IL2CPP's internal error on `Unsafe.Unbox<T>` in a generic class, without LsMsgPack (variants `UNBOX`, `STRONGBOX`, `CAST`, combined with `ONLY_PLAIN`/`ONLY_VECTOR3`), for a report to Unity; LsMsgPack works around it (`LsMsgPackCore/Meta/BoxedValue.cs`).
- IL2CPP's `float.NaN`/`double.NaN` are positive NaNs (CoreCLR's negative): the sample builds its NaNs from their bits.
- `.gitignore`: Unity's Library/Logs/UserSettings, Builds, out, the copied DLLs and the scenes and link.xml the build script writes; `.meta` files are re-included (the root ignores them).

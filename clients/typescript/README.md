# @lsmsgpack/client

Reads the `application/x-lsmsgpack` responses of [LsMsgPack's ASP.NET formatters](https://github.com/mlsomers/LsMsgPack/blob/master/docs/WebFormatters.md) into complete JavaScript objects, and writes request bodies they read, in browsers and Node 18+:

- every property of the .NET class is there, also the ones the server left out (`null`, `0`, `false`, `[DefaultValue]`...);
- polymorphic values get the properties of their actual class, and its name in `$type`;
- the schema (the property names) is sent once, then the server refers to it;
- optional generated models ([lsmsgpack-ts](https://github.com/mlsomers/LsMsgPack/blob/master/docs/TypeScriptModels.md)): instances of TypeScript classes with the values the .NET constructors set, typed request bodies, and the server's schemas held before the first request.

No dependencies. Request bodies are sent as plain MsgPack (`application/msgpack`), with `$type` as the type id: polymorphic bodies work too.

```ts
import { LsMsgPackClient } from '@lsmsgpack/client';

const api = new LsMsgPackClient({ baseUrl: 'https://example.com/' });
const invoice = await api.get<Invoice>('api/invoices/42');
await api.post('api/invoices', invoice);
```

With the generated models and schemas:

```ts
import { models } from './api/models';
import { schemas } from './api/models.schemas';

const api = new LsMsgPackClient({ baseUrl: 'https://example.com/', models, schemas });
```

Documentation: [docs/TypeScriptClient.md](https://github.com/mlsomers/LsMsgPack/blob/master/docs/TypeScriptClient.md) (options, the models, value conversions, polymorphic request bodies, CORS, the described schema).

## Development

```bash
npm install
npm test                                # builds, then runs test/*.test.mjs (node:test)
dotnet build test-server                # enables the tests against the ASP.NET Core formatters (skipped without it)
dotnet build ../../LsMsgPackTypeScript  # and the ones with models generated by lsmsgpack-ts (test/generated/)
npm run bench                           # reading and writing 100 invoices: JSON, @msgpack/msgpack, this client with and without models (needs the test server)
```
